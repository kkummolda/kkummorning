1단계 기술기획 패널 (Technical Spec Panel)

시각화된 기술기획서 본체

📌 요구사항 (PRD-01)

  • 5분(300초) SVG stroke-dashoffset 카운트다운 타이머
  • Start, Pause, Reset 제어 및 타이머 상태 텍스트 변경
  • 4종 백색소음/오르골 오디오 믹싱 및 볼륨 슬라이더

🛡️ 데이터 계약 (CON-01)

  • Inputs: sound_type ('rain'|'forest'|'musicbox'|'fire'), volume (0.0~1.0)
  • Outputs: timer_elapsed_seconds (Integer)
  • Sync: user_profiles.sound_type / volume 설정값 클라우드 저장

⚡ 비기능 요구사항 (NFR-02)

  • Web Audio Context 메모리 누수 방지 (close() 디스포즈)
  • 백그라운드 탭 이동 시 setInterval 오차 자동 보정
  • Web Audio API 오실레이터 폴백 백색소음 탑재
