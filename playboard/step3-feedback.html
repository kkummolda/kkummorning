📌 요구사항 (PRD-03)

  • 자아·가정·사회·영혼 4대 영역 피드백 및 한 줄 요약 입력
  • 날짜 선택 시 해당 일자의 기존 일기 자동 불러오기 (Read)
  • Supabase Postgres DB (`daily_logs`) 실시간 Upsert (Create/Update)

🛡️ 데이터 계약 (CON-03)

  • Table: public.daily_logs
  • Composite Unique Constraint: UNIQUE(user_id, date)
  • Payload: { user_id, day, date, self_feedback, family_feedback, society_feedback, soul_feedback, one_sentence_summary }

⚡ 오프라인/복구 엔진 (DOM-INTEGRITY)

  • LocalStorage 1차 즉시 저장 (네트워크 단절 대처)
  • Supabase 연결 시 백그라운드 롤업 업로드
  • Toast 알림 z-index: 4000 보장
